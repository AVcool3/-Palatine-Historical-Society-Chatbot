# Sources for the seeded historical records

The Markdown files in this folder were compiled from public reference material
gathered via web search. They are a **starting seed** for the chatbot's
knowledge base. For the fullest and most current information, run the scrapers
in `scripts/` from a machine with normal internet access.

## A note on accuracy

Dates and figures were transcribed carefully but should be verified against the
primary sources before being treated as authoritative. Museum hours and contact
details in particular change over time.
