Put photos of documents, letters, newspaper clippings, or postcards in THIS folder.

Supported: .jpg .jpeg .png .webp .gif .heic .tif .tiff

Then run:  python scripts/transcribe_photos.py

For each photo, a matching "<name>.transcription.md" file is written next to it
containing the transcribed text. Those transcriptions are then searchable by the
chatbot.
